# 👻 Boo Puzzle

과거의 나(유령)와 협동하여 탈출하는 시간 루프 퍼즐 게임입니다. (총 4개 월드, 120개 레벨 지원)

## 🎮 플레이하기
👉 **[Boo Puzzle 웹에서 바로 플레이하기](https://njy0830.github.io/Boo-Puzzle/)**

## ⌨️ 조작 방법
* **이동**: `A` / `D` 또는 `←` / `→` 키
* **점프**: `Space`
* **상호작용**: `E`
* **루프 재시작 (되감기)**: `R`

## 🌍 월드 구성
* **World 1 (녹색의 연구실)**: L1 ~ L30 (기동 훈련, 1유령)
* **World 2 (푸른 심해 시계탑)**: L31 ~ L60 (시간차와 이중 기믹, 2유령)
* **World 3 (보랏빛 황혼 기지)**: L61 ~ L90 (복합 릴레이, 2~3유령)
* **World 4 (붉은 동결 요새)**: L91 ~ L120 (최종 한 줄 로그, 3유령)
